## 1. 优先级分层

**排序依据（对齐赛题验收项）**：验收以 **①功能完整性（实现全部功能点/功能演示）②易用性（开箱即用/功能测试）③交付物完整性（可执行程序+源代码+文档/清单核对）** 为准。→ **凡"能在评委面前演示通"的即为 P0，且 P0 必须 100% 覆盖 6 项硬功能**；能显著提升演示质量与验收评分的稳定性/易用性为 P1；加分型非必需功能为 P2。

### 1.1 P0 — 硬功能与交付物（缺一不可，全部必演示）

| # | 功能/交付物 | 对应验收项 | 交付定义（DoD） |
|---|------------|-----------|----------------|
| P0-1 | 多源数据抓取（政府/园区官网、政务平台） | 功能完整性 | ≥3 类真实源可跑通，落库可复现 |
| P0-2 | 政策智能处理：识别有效政策 + 按类型/层级/行业分类 | 功能完整性 | 分类标签可视、可导出 |
| P0-3 | 关键信息提取（名称/申请条件/截止日期/补贴标准等） | 功能完整性 | 结构化字段 ≥5 项，缺失可标注 |
| P0-4 | 简报生成与导出（XLS/PDF/Doc） | 功能完整性 | 一键生成且三种格式均可打开 |
| P0-5 | 图形化界面（GUI） | 易用性 | 全程鼠标可操作，无需命令行 |
| P0-6 | 性能稳定：功能可实现、运行无崩溃 | 易用性/功能测试 | 演示全流程无崩溃、可重复运行 |
| P0-7 | 交付物三件套：可执行程序 + 源代码 + 文档 | 交付物完整性 | 一键启动 + README + 清单核对表 |

### 1.2 P1 — 提升演示质量与稳定性上限（强烈建议）

| # | 功能 | 价值 | RICE（R×I×C/E） |
|---|------|------|----------------|
| P1-1 | 抽取准确率评测集 + 阈值校准 | 决定"真能用"还是"能演示" | 8×9×0.7 / 3 ≈ **16.8** |
| P1-2 | 反爬/限速/重试/本地缓存 | 演示不因封禁翻车 | 7×9×0.8 / 2.5 ≈ **20.2** |
| P1-3 | 一键运行/配置向导（开箱即用） | 直接命中"易用性"验收 | 9×8×0.9 / 2 ≈ **32.4** |
| P1-4 | 抓取调度 / 增量更新 | 体现"全自动化"卖点 | 6×7×0.7 / 3 ≈ **9.8** |
| P1-5 | 导出格式增强（模板/字段映射/批量） | 演示观感与实用性 | 6×6×0.8 / 2 ≈ **14.4** |

### 1.3 P2 — 加分/可裁剪（时间不足即砍）

| # | 功能 | 说明 |
|---|------|------|
| P2-1 | 多地区/多语言扩展 | 展示扩展性 |
| P2-2 | 简报模板自定义（拖拽/主题） | 锦上添花 |
| P2-3 | 数据看板/可视化图表 | 演示加分项 |
| P2-4 | 账号/权限/多用户 | 非赛题必需 |
| P2-5 | 定时推送（邮件/IM） | 可延后 |

> **裁剪原则**：任一 P1/P2 若威胁到 P0 任一项的"可演示/无崩溃"，立即降级或砍除。

## 5. 利益相关者沟通要点（三版本）

### 5.1 高管 / 评委版（价值与演示亮点）
1. **一句话价值**：把"全网找政策—读政策—写简报"从数小时人工压缩到**一键、分钟级**，标准化输出。
2. **演示主线**：选一个真实区县，现场演示"输入筛选条件→自动抓取→分类打标→导出 PDF 简报"全流程，**3 分钟内跑完**。
3. **对齐验收**：6 项硬功能逐项演示、开箱即用一键启动、交付物清单现场核对，全部命中评分标准。
4. **差异化**：不限单一数据源、LLM 语义抽取保证"有效政策识别"，非关键词堆砌。
5. **风险透明**：唯一不确定项是时效加分窗口（原线已过），已按常规截止推进，不影响交付质量。

### 5.2 工程版（技术优先级与依赖）
1. **优先级**：先保 P0 六功能端到端可演示，再谈 P1 稳定性/易用性，P2 一律后置。
2. **依赖链**：抓取层上线是 M2 前置；**字段 schema 冻结**是 M3/M4 并行的前提，务必按 M2 中段锁死。
3. **稳定性优先于功能**：R5 无崩溃为验收硬指标，提交前必须连续 3 次彩排通过。
4. **反爬工程**：限速/重试/缓存/多源冗余为必做，不做则演示有翻车风险。
5. **接口契约**：抓取→清洗→抽取→存储→导出 各层统一数据结构，避免联调返工。

### 5.3 设计版（体验关键点）
1. **开箱即用**：首次启动提供配置向导（选地区/选政策类型/一键开始），用户零学习成本。
2. **单页流程**：搜索→结果列表→分类筛选→导出，一条动线走完，**鼠标全程可操作**。
3. **进度可见**：抓取/处理过程有进度与状态反馈，避免"卡死"错觉（呼应无崩溃验收）。
4. **结果可读**：政策卡片突出名称/截止日期/补贴标准等关键字段，支持一键导出简报。
5. **容错友好**：抓取失败/字段缺失有明确提示与兜底展示，不抛异常、不白屏。
