## 3. 用户研究洞察

来源：瑞思（用户研究）。以下为对 PRD 有约束力的核心结论。

**画像与现状**

- ①**李老板**（中小微企业主/创业者）：靠朋友告知+微信群+百度，信息滞后被动。
- ②**王专员**（政策申报专员）：每天刷十几个部委/园区官网+Excel 台账，重复劳动重。
- ③**陈经理**（园区招商/企业服务）：需给 200 家入驻企业推政策，人工无法规模化。
- ④**张会计**（代账/中介）：为 50+ 客户找政策，串行处理效率低。

**5 类痛点**：获取难（政策散在部委/省/市/区县/园区上百入口）、筛选难（无效/过期/非本地占比高）、理解难（术语多、条件嵌套）、跟踪难（更新与截止无人提醒）、输出难（手工敲 Word、格式不统一）。

**需求优先级（用户感知）**

| 需求 | 优先级 | 落到需求池 |
|---|---|---|
| 全网自动检索 | 高 | FR-1.x、FR-2.x |
| 自动过滤+分类 | 高 | FR-2.3 / FR-2.4 / FR-2.6 |
| 关键字段结构化 | 高 | FR-3.x |
| 原文可溯源 | 高 | FR-1.7 / FR-3.11 |
| 截止/新增提醒 | 中高 | FR-6.1 |
| 一键生成简报导出 | 中高 | FR-4.x |
| 免注册免配置开箱即用 | 中 | FR-5.6 / NFR-7 |
| 多企业批量管理 | 中 | FR-7.x |

**5 条洞察（设计红线）**

1. **可信度 > 花哨功能**：每条结论须能一键溯源原文，**宁少而准**，不做无依据推断。
2. **「开箱即用」是留存门槛**：强制注册/配置会劝退用户 → GUI 首启即可用内置源完成一次检索（FR-5.6）。
3. **结果要「可执行」而非「可阅读」**：默认回答"我能申吗 / 何时截止 / 交什么材料"三问（FR-3.4/3.5/3.7）。
4. **提醒是刚需闭环、是黏性钩子**：截止与新增提醒决定回访（FR-6.1）。
5. **输出物要能二次使用**：格式标准化+一键导出，提升专业用户采纳（FR-4.x）。

**旅程差异**：当前「人找政策 → 多入口手动拼 → 经验判断」→ 理想「**政策找人** → 一次输入全自动聚合 → 结构化+可溯源可信输出」。

| 企信平台政策板块（天眼查/企查查） | ⚠️ | ⚠️ | ❌ | ⚠️粗 | ❌ | ⚠️ | ❌ | 部分付费 | T+1 更新、分类粗、无简报 |
| **本产品（AI政策搜索智能体）** | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | 低成本 | 无工商库/无政务背书/冷启动/反爬维护 |

**竞品薄弱环节 = 机会点**

1. 「**找得到 ≠ 能报**」断层：竞品止步于信息呈现，缺少"条件是否满足/何时截止"的确定性判断。
2. 注册/付费墙劝退小微企业：免登录是本产品核心差异。
3. 地域孤岛：跨省创业者无法一站式获取。
4. **几乎无竞品直接产出可转发存档的标准简报**（交付物空白）。
5. 时效与去重差：T+1、重复条目多。

**SWOT**：S=免登录开箱即用 / 多源全国+本地兼采 / 结构化+简报一体 / 低成本；W=无工商数据库 / 无政务背书 / 冷启动 / 反爬维护成本；O=政务AI 2025 刚起且未跨域整合 / 「能报什么」确定性需求强 / 简报交付物空白；T=资本+数据壁垒 / 政务免费下沉 / 搜索引擎语义升级 / 反爬升级。

**差异化机会（5 条，转为需求约束）**：①免登录+本机运行+简报直出三合一（FR-5.6/NFR-9）；②截止日期+申报条件结构化+到期提醒（FR-3.4/3.5、FR-6.1）；③标准化一页纸简报体裁（FR-4.2）；④多源交叉去重+权威度排序（国家>省>市>园区）（FR-2.2/FR-2.5）；⑤面向园区/中介的批量速配轻量版（FR-7.1）。

## 7. 关键流程 / 系统架构与界面说明

### 7.1 端到端主流程

```
输入查询(自然语言/表单)
      │
      ▼
[1] 查询解析 → 地域/行业/关键词/时间条件
      │
      ▼
[2] 多源抓取(适配器层) ── 内置源清单(政府/园区/政务平台) + 增量水位
      │                    ├─ 限速/重试/断点续传(FR-1.5/1.6)
      │                    └─ 原始快照留存(FR-1.7)
      ▼
[3] 清洗去重 ── 正文抽取(FR-2.1) → 跨源去重(FR-2.2)
      │
      ▼
[4] AI结构化 ── 有效性判定(FR-2.3) → 字段抽取Schema(FR-3.x) → 置信度(FR-3.10)
      │
      ▼
[5] 分类与排序 ── 类型/层级/行业分类(FR-2.4) → 权威度排序(FR-2.5) → 相关性过滤(FR-2.6)
      │
      ▼
[6] 简报生成 ── 模板引擎(FR-4.1) → 一页纸简报(FR-4.2)
      │
      ▼
[7] 导出 ── XLS / PDF / Doc (FR-4.3~4.6) + 提醒(FR-6.1)
      │
      ▼
GUI 展示(列表/详情/溯源/导出)  ── 全程可溯源、字段可一键回原文
```

### 7.2 模块划分

| 模块 | 职责 | 对应需求 |

| 交付层（Reporter） | 模板引擎、简报生成、多格式导出、元数据 | FR-4.x |
| 调度层（Scheduler） | 定时任务、增量调度、失败重试、状态监控 | FR-1.4/1.6、NFR-1/2 |
| 界面层（GUI） | 查询、列表、详情、溯源、导出、监控面板 | FR-5.x |

### 7.4 关键交互原则（来自用户洞察）

- 首屏即"可执行答案"：默认回答**能申吗 / 何时截止 / 交什么材料**三问。
- 一切结论**可溯源**：字段旁提供原文定位入口。
- **免注册免配置**：不设登录墙，配置项后置。
- 低置信字段**显式标注**，不臆造。

## 8. Non-goals（明确不做什么）

| 编号 | 不做 | 理由 |
|---|---|---|
| NG-1 | **不做政策申报代办/代提交** | 涉及资质与法律责任，超出"搜索+简报"范围 |
| NG-2 | **不做政策法律解读/申报成功承诺** | 规避法律意见风险，仅提供原文与结构化事实 |
| NG-3 | **不做企业工商信息数据库** | 无数据源与维护能力（SWOT 劣势项），"匹配"仅基于用户输入画像 |
| NG-4 | **不做政策全文存档再分发/镜像站** | 版权与合规风险，只保留溯源链接与必要快照 |
| NG-5 | **不覆盖非企业扶持政策**（如个人社保/教育/医疗） | 聚焦赛题"企业扶持政策"（补贴/场地减免/稳岗等） |
| NG-6 | **不做境外政策** | 明确"全国各级政府"范围限于中国大陆 |
| NG-7 | **不做实时毫秒级抓取** | 纳入增量调度即可，避免高频请求触发反爬与合规风险 |
| NG-8 | **v1 不做多用户云端协同/账号体系** | 本机运行、免登录是核心差异，账号体系留待 v2 |

## 10. 数据字段规格（关键字段 Schema）

政策主表字段定义。类型标注：`str` 字符串、`date` 日期、`enum` 枚举、`list` 列表、`num` 数值、`url` 链接。

| 字段名 | 中文名 | 类型 | 必填 | 示例 | 抽取难点说明 |
|---|---|---|---|---|---|
| `policy_id` | 政策唯一ID | str | 是 | `P2026-ZJ-HZ-000123` | 系统生成，需结合源+去重指纹生成稳定 ID |
| `policy_name` | 政策名称 | str | 是 | 《杭州市制造业企业技改补贴实施办法》 | 标题常含书名号/后缀"的通知"，需规范化去除冗余 |
| `issuer` | 发布机构 | str | 是 | 杭州市经济和信息化局 | 多部门联合发布需拆分为列表；简称与全称需归一 |
| `gov_level` | 政策层级 | enum | 是 | 省级/市级/区县级/园区级/国家级 | 从机构名与来源域名推断，园区级易与区县级混淆 |
| `applicable_industry` | 适用行业 | list(enum) | 是 | 智能硬件、软件信息服务 | 行业表述不统一（如"专精特新""制造业"），需映射到统一行业树 |
| `policy_type` | 政策类型 | enum | 是 | 补贴/场地减免/稳岗/税收/融资/人才/研发奖补 | 单政策可能多类型；边界模糊（如"奖励"vs"补贴"） |
| `apply_conditions` | 申请条件 | list(str) | 是 | ["注册满2年","营收≥2000万","无重大违法"] | 条款嵌套（且/或、例外），需保留层级；口语化表述需结构化 |
| `deadline` | 截止日期 | date/str | 是 | 2026-06-30 | 常表述为"自发布之日起30日内""长期有效""随到随受理"，需折算或标记 |
| `publish_date` | 发布日期 | date | 是 | 2026-03-01 | 需区分发布日期/印发日期/成文日期 |
| `validity_period` | 有效期 | str | 否 | 2026-01-01 至 2026-12-31 | 缺失时需以截止日期或"长期有效"表达 |
| `subsidy_standard` | 补贴标准/金额 | str | 是 | 按设备投资额10%补贴，单户上限200万 | 比例+上限+分档并存；需保留数值与计量单位 |
| `apply_materials` | 申报材料 | list(str) | 否 | ["申请表","营业执照复印件","审计报告"] | 材料常以附件形式给出，正文可能仅提"详见附件" |
| `contact` | 联系方式 | str | 否 | 0571-xxxx / xxx@gov.cn | 有则必抽、无则标空；不得臆造 |
| `source_url` | 原文链接 | url | 是 | https://... | 需保证可打开；跳转页需还原真实详情 URL |
| `source_snapshot_ref` | 原始快照引用 | str | 是 | `snap://P2026-...-a1` | 用于溯源，保存抓取时点原始内容 |
| `source_name` | 来源站点 | str | 是 | 杭州市经信局官网 | 去重合并后需保留多来源 |
| `authority_rank` | 权威度分值 | num | 是 | 5（国家=5…园区=1） | 排序依据，需可配置 |
| `is_valid` | 是否有效 | bool | 是 | true | 过期/失效/征求意见稿需标记 |
| `extract_confidence` | 抽取置信度 | num(0–1) | 是 | 0.93 | 低于阈值(默认0.8)字段标"待核验" |
| `fetched_at` | 抓取时间 | datetime | 是 | 2026-04-01T08:00:00+08:00 | 时效性判断依据 |
| `dedup_fingerprint` | 去重指纹 | str | 是 | `sha1(name+issuer+date)` | 跨源合并主键，需容忍转载差异 |
